# Analise Exploratoria de E-commerce Brasileiro

Analise exploratoria de dados (EDA) do dataset publico de e-commerce da Olist, utilizando Python, Pandas e bibliotecas de visualizacao.

## Objetivo do Projeto

Analisar padroes de vendas, comportamento de clientes e desempenho de produtos em uma base de dados real de e-commerce brasileiro, gerando insights acionaveis para negocio.

## Dataset

**Fonte:** [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-e-commerce)
- 100k pedidos (2016-2018)
- Dados reais anonimizados
- Multiplas tabelas relacionais

## Perguntas de Analise

1. Qual a evolucao mensal de vendas?
2. Quais estados e cidades mais compram?
3. Quais categorias de produtos mais vendem?
4. Qual o tempo medio de entrega?
5. Qual a correlacao entre nota de avaliacao e recompra?
6. Quais formas de pagamento sao mais utilizadas?
7. Existe sazonalidade nas vendas?

## Tecnologias

- Python
- Pandas (manipulacao de dados)
- NumPy (calculos numericos)
- Matplotlib & Seaborn (visualizacao)
- Plotly (graficos interativos)
- Jupyter Notebook
